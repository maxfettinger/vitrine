The `example` shortcode is what Vitrine is named after: a glass case with the real thing inside. A folder of up to
three files becomes a running demo, and the same files, unchanged, appear in tabs below it. What readers copy is
what ran.

Start with [the example shortcode](example-shortcode/), then read how [styles, scripts and imports](styles-and-scripts/)
stay inside their example and load libraries.
